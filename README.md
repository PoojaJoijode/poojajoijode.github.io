# Pooja Joijode Portfolio Website

React and Vite portfolio website for a Data Scientist / Applied Analytics / BI profile.

## Included Updates

- Professional profile photo in the hero section
- Resume PDF download
- Updated experience from latest resume
- Updated project cards from latest resume
- Hover, active, focus, and card motion interactions
- Light and dark theme support
- GitHub Actions deployment for GitHub Pages

## Tech Stack

- React
- Vite
- Modular CSS
- GitHub Pages
- GitHub Actions

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Push to the `poojajoijode.github.io` repository. The included workflow builds the Vite app and deploys the `dist` folder through GitHub Actions.

In GitHub, set:

```text
Settings > Pages > Build and deployment > Source > GitHub Actions
```
